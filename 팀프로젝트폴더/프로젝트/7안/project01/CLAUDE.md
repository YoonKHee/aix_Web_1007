# 감독? 내가한다! — 작업 인계 (Claude Code용)

K리그1 BEST11 플랫폼. Django 6.1, Python 3.13, SQLite. 3인 팀: 윤건희(팀장), 이상훈, 나은철.
먼저 `AGENTS.md`의 규칙을 읽는다. 특히 **가중치를 임의로 바꾸지 않는다**(바꾸려면 변경 전/후 순위 비교를 먼저 보여준다).

## 소유 범위
- 내 담당: `manager`, `board`, `home/index.html`
- 공유(수정 전 팀원 확인): `player/templates/player/best11.html`, `team/*`, `player/urls.py`
- 사용자는 파이썬 초보(Windows PowerShell + venv). 설명은 짧고 쉬운 말로, 코드는 고칠 줄만 보여준다.
- 파일은 검토를 끝낸 뒤 사용자가 요청할 때만 전달한다. 푸시·삭제는 요청받았을 때만 한다.

## 구조 (감독 연구실 패치)
- `player/lab/` : 엔진 + JSON API (`path('lab/', include('player.lab.urls'))`)
  - `service.py`(능력 점수·API·보고서), `chemistry.py`(케미), `club_profile.py`(구단 유형), `tuning.py`(상대 맞춤),
    `management.py`(피로·경고), `analysis.py`, `quality.py`, `reports.py`(선수별 보고서 JSON), `views.py`, `urls.py`
- `player/static/player/` : `best11_edit.js`(BEST11 화면 전체 제어), `lab.js`, `lab.css`, `radar_grow.js`, `data/player_reports.json`
- `player/templates/player/lab_panel.html` : `best11.html` 맨 아래 `{% include 'player/lab_panel.html' %}` 한 줄로 연결
- `team/static/team/match_fatigue.js` : 모의 경기 피로 (`lineup_simulation.html`에 스크립트 한 줄)
- `python manage.py build_player_reports` : 선수 기록이 바뀌면 보고서 JSON 재생성
- 상태는 서버에 저장하지 않는다(stateless POST). 브라우저 localStorage: `kleague-my-best11-v1`(라인업), `kleague-b11-settings-v1`(설정)

## 계산 규칙 요약
- 능력 점수: 포지션별 가중치 × (값 / 포지션 최대), 개수 지표는 90분당. 가중치는 `player/services.py`의 `FW/MF/DF/GK_WEIGHTS`.
  - FW 득점35·도움20·유효슈팅15·슈팅10·키패스10·드리블10 / MF 도움20·키패스20·패스성공률20·득점15·회수10·인터셉트10·드리블5
  - DF 클리어링20·인터셉트20·회수15·태클15·공중볼10·지상볼10·수비블록5·블록5 / GK 평점50·베스트11 25·MOM15·출전10
  - 소표본 보정: 450분 미만이면 평균 쪽으로(0.85×평균). 경험 보정: 1800분 미만이면 최대 30% 감점(`EXPERIENCE_*`, 슬라이더 기본 1.5)
- 케미: 쌍 점수 = 보완55 + 연계35 + 같은 팀10(같은 스타일 구단은 5). 70↑ +3, 55↑ +1.5, 약점 중복 -1. 선수당 -2~+5, 450분 미만은 절반. 최종 점수 상한 200
- 구단 유형: 구단 지표 z점수로 점유/직선/측면/압박 중 최고점(≥0.5), 아니면 균형형
- 포메이션 추천: 최종 점수 합을 "리그 같은 포지션 주전급(450분↑) 평균 대비 점수(vs_avg)"로 순위(백분위 아님)
- 보고서 등급: 20–80 스케일(50=포지션 주전급 평균, 10점=표준편차 1, 5점 단위), 스카우트 의견 A~D

## 화면 구성 (best11_edit.js)
- 도구 모음(프리셋·지표 배율·케미·경험·상대 맞춤), 카드 점수 옆 케미 색 숫자 + 이유 한 줄, 포메이션 추천, 교체·대체 보고서, 상대 맞춤 보고서
- 선수 팝업: 케미 태그, VS 비교(SVG 레이더 겹침·보정 점선), 🤝 케미 파트너, 📋 스카우터 양식 보고서, 90분당 주요 기록 가로바(기존 박스 대체)
- 설정이 기본값이면 보고서는 `player_reports.json`, 바뀌었으면 서버에서 그 설정으로 재계산 + 기본 대비 변화 표시
- **카드 정렬 주의:** 화면 줄 순서는 FW→MF→DF→GK, 서버 라인업은 GK→DF→MF→FW. `best11_edit.js` 시작 부분에서 카드를 서버 순서로 재배열한다(공격수 칸에 골키퍼가 들어가던 버그의 수정).

## 데이터 한계 (거짓 숫자를 만들지 말 것)
- 선수 기록은 2026 시즌 하나뿐(433건). 2025 기록, 경기별 선수 기록, 경기별 라인업, 패스 주고받기 데이터가 없다
- 그래서 "2025 vs 2026", "최근 5경기", "출전 여부에 따른 팀 성적", "전술 이해" 능력치는 만들 수 없다
- 승부예측 모델(team/match_prediction.py): 홀드아웃 로그손실 1.150으로 무작위(1.099)보다 나쁨, 무승부 예측 안 함. 라인업 효과는 최대 8%p의 규칙. 학습은 2026-10-24 경기까지
- 가중치 선정 이유는 코드·문서에 없다(만든 사람에게 확인 필요). 평점과의 상관: FW 0.83, MF 0.56, DF 0.48. MF 패스성공률(-0.17), DF 클리어링·인터셉트(0.07)는 근거가 약하다. 단 가중치를 ±50% 바꿔도 포지션별 상위 선수는 대부분 유지된다
- 케미는 패스 데이터가 없어 보완·연계·같은 팀으로 추정한 값이며 실제 호흡과 맞는지 검증하지 못했다
